# Project 3 Design Concept

## Project Summary

For Project 3, our group is thinking of designing a speculative communication network called **Discovering Utopia**. The main idea is that users communicate primarily through **images** instead of depending only on long written language. The goal is for Users to be able to upload images and describe them using a **fridge magnet poetry style**, where words can be selected, arranged, and combined to create meaning in a more playful and visual way.

The project imagines a network where people collectively build a vision of a better future. Instead of only debating with text, users shape that future by sharing images, arranging words, and deciding what should be kept, improved, or removed from society.

**Discovering Utopia** will be a speculative communication platform where users express ideas for a better world through images, symbols, and rearranged text fragments. The project will try to explore how communication could happen in a more visual and interactive way, where meaning is built through selection, placement, and collaboration rather than traditional writing alone.

## Research and Inspiration

Our group looked at references connected to speculative design, visual communication, and collaborative meaning making.

One important reference was the [**Blackout**](https://tilde.town/~kc/blackout/) website. That site helped inspire the idea of creating communication through **selection and arrangement** instead of just typing a normal paragraph. We were interested in how meaning can be built by choosing fragments and organizing them in a new way.

We were also inspired by image based platforms and collage like interfaces. The moodboard shows both **utopian** and **dystopian** visual directions. One side shows a dark, crowded, destructive world, while another side shows a brighter, more hopeful, natural world. This contrast helps support the concept of discovering what kind of future people actually want.

Another important visual reference is the **fridge magnet poetry** style. It gives the interface a playful but meaningful interaction, because users are not only uploading images, but also creating small messages out of movable or selected words.

## Moodboard Direction

The visual style of the project is influenced by both futuristic and internet based communication spaces. The moodboard shows a contrast between chaos and hope.

Some important visual ideas from the moodboard are:

- bright, colorful, pixel like visual worlds
- dark dystopian imagery
- collage and archive aesthetics
- free placement of images and text
- magnetic poetry / word fragments
- playful but reflective interface design

This helps the project feel like a speculative communication network instead of a normal social media site. Right now, the main planned pages are:

### 1. Home / Utopia Feed
This will be the main feed where users upload images and communicate through visual posts. Users can place images and add short magnet style text to describe what they are imagining.

### 2. Trash Page
This page will show images or ideas that users think should be removed from a better future. It works like a discard archive.

### 3. Profile Page
This page will represent the user’s identity visually, possibly through swatches, icons, names, or other small visual markers. 

### 4. Poll Page
This page will allow anonymous voting on socially relevant topics. It adds a collaborative and participatory side to the project. Though, we will try to implement this page as we will be working on the Home, Trash, Profile page in order to see the final result.  

## Wireframe Notes

Our wireframe is focused on **free range image and text placement**. Instead of a very strict grid, the page will allow more open composition. This supports the concept because communication in this world is less fixed and more expressive.

The wireframe also shows that users can upload images and describe them using **fridge magnet poetry text**. This is one of the most important features because it connects directly to the idea of communication beyond normal language.

The design direction is more open, flexible, and interactive rather than heavily structured.

## Technical Direction

The project will use:

- **Express**
- **Nunjucks**
- **response.render()**

The frontend will focus on layout, visual styling, and interactive communication design.  
The backend will focus on routes, rendering pages, handling uploads, and managing the stored content.
