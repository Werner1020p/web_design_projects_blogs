# Project 2 Documentation

## Project Summary

For Project 2, my group created a full stack album website. The idea of the project was to make a website where users can view different albums, click on an album, and see more detailed information about it. The project uses Nunjucks templates for the page structure, neDB for the database, and server side rendering to display the pages.

Our website includes a home page, an about page, a form page, and individual album pages. The album covers appear at the top, and when the user clicks one of them, the site opens a page with more information about that album.

## My Contribution

My main contribution to this project was working on the visual design and layout of the website. I focused mostly on the `styles.css` file and helped improve how the pages looked and how the content was organized.

I worked on the colors, spacing, typography, footer styling, album page layout, and general visual consistency. I wanted the website to feel more polished and more connected as one full project instead of separate pages with different styles.

I also helped improve the structure of some of the `.njk` files so the styling could work better across the pages.

## Files I Worked On

These are the main files I worked on:

- `public/styles.css`
- `views/nav.njk`
- `views/about.njk`
- `views/album.njk`
- `views/footer.njk`

## What I Changed

I worked on improving the color palette, typography, spacing, footer alignment, and the album page layout. I also focused on making the different pages feel consistent with each other, so the home page, album page, about page, and form page all looked like they belonged to the same project.

## Challenges

One challenge I worked through was keeping the album covers displayed at the top while also making sure the selected album information appeared clearly underneath. Another issue was fixing the footer credits so they lined up correctly and looked more balanced. Overall, I had to make a lot of small design adjustments to keep the layout clean, readable, and visually organized.
