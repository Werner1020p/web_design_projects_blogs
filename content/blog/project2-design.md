## Project Overview

For Project 2, my group is building a custom API using a curated dataset in JSON format. The concept my group developed is a **music album showcase** — where users can browse album covers in a grid, click one, and see details like artist, release date, album length, and more. The site may also play a short audio snippet and switch color themes based on the selected album.

### Approach Chosen

Our group chose:
**Curating and scraping data into a new dataset (in JSON format)**  
This means we will collect and structure our own data rather than using an external API.

## My Role – Design & Front-End Layout

I am responsible for the **design and visual layout** of our project. Specifically, I will handle:

- Creating wireframes for the homepage and album detail views
- Defining the visual style, including layout, spacing, and typography
- Choosing the overall aesthetic direction (black/white theme with dynamic color accents)
- Planning how the JSON data will be presented (album grid, filters, click interactions)
- Designing the interactive behavior (click → detail view, color theme shifts)

The goal is to design a clear and engaging user interface that makes browsing albums enjoyable and intuitive.

---

## Design Decisions So Far

### Aesthetic

We agreed on a minimal, mostly black and white theme that lets the album covers stand out. When a user selects an album, the color scheme dynamically changes to match the album’s dominant colors.
