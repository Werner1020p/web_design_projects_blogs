Project 1 – Blog Design

  • 11 February 2026

Theme

For this project I designed a personal media blog. I chose this theme because I am interested in film, creativity, and digital media.

Design Process

I explored the structure of the Eleventy blog template and learned how layouts and content files work.

Changes I Made

  • Changed the blog title and metadata
  • Removed starter instructions
  • Added a custom introduction to the homepage
  • Modified homepage CSS
  • Styled individual blog posts
  • Updated the About page

Challenges

At first it was confusing to understand where layouts and content were located, but after testing changes I understood the structure.

What I Learned

I learned how static site generators work and how CSS and layouts can quickly change the design of a website.
